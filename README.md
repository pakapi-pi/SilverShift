# シルバー職員用 4週間シフト v1.1

6人を上・下3人ずつに分け、前回3日と今回28日のシフトを入力・自動作成する、ブラウザだけで動く静的Webアプリです。

今回28日分は、上・下グループごとに「配置不要」を指定できます。指定日はそのグループの必要勤務日数から除外されます。

## ローカル起動

`index.html` をダブルクリックしてブラウザで開きます。サーバー、ビルド、外部ライブラリは不要です。

## GitHub Pages（最短手順）

1. 4ファイルをリポジトリのルートへ置いて push。
2. GitHub の **Settings → Pages** で `Deploy from a branch`、対象ブランチの `/ (root)` を選び Save。
3. 表示されたURLを開く。

職員データはブラウザの localStorage にだけ保存されます。GitHubへ職員データを送信する処理はありません。
